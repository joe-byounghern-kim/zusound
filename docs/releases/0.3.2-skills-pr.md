### Release-auto dry-run qualification

Before versioning, the dry-run recognized the existing patch Changeset and skipped automatic generation. After Changesets consumed it, the default history-based dry-run returned exit 0 but suggested **minor**, because the nearest ancestor release tag on this development history is older than the release-branch `v0.3.1` tag. That suggestion was **not applied** and did not alter 0.3.2.

With the actual release delta explicitly selected, `RELEASE_RANGE=v0.3.1..HEAD pnpm release:auto:dry-run` returned exit 0 and suggested **patch**. This is not an unqualified claim that default automatic bump inference is correct on this branch history. The existing tag-only Release workflow does not run Changesets version preparation. Review the intended release range before any future auto-generation.
